# Simple Interest Calculator

A simple calculator that computes Simple Interest based on the principal amount, annual rate of interest, and time period.

## Description

This project provides a simple Bash-based calculator that calculates Simple Interest using the standard formula:

Simple Interest = (Principal × Rate × Time) / 100

The calculator accepts user input and displays the calculated simple interest.

## Features

- Accepts principal amount as input
- Accepts annual rate of interest as input
- Accepts time period in years as input
- Calculates simple interest using the standard formula
- Displays the result to the user

## Formula

SI = (P × R × T) / 100

Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time Period (Years)
- SI = Simple Interest

## Input

The calculator requires the following inputs:

- Principal amount
- Rate of interest
- Time period in years

## Output

The calculator displays:

- Calculated Simple Interest

## Example

### Input

Principal: 1000

Rate: 5

Time: 2

### Output

Simple Interest = 100.00
